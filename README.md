# ERL-HUB
### Post-Earthquake Multi-Agency Emergency Relief Logistics Hub

## Project Overview
ERL-HUB is a C++ based emergency relief management system designed to coordinate disaster response operations following an earthquake. It manages transport vehicles, essential supplies, inventory, and emergency dispatch operations.

## Key Features
- Emergency vehicle and fleet management
- Relief supply allocation and inventory tracking
- Route evaluation and fuel management
- Cargo and manifest management
- Emergency dispatch and audit records
- Exception handling and data persistence

## Concepts Implemented

**Unit I – Core Foundations**
- Namespaces, Function Overloading
- Call and Return by Reference
- Inline Functions and Friend Class

**Unit II – Encapsulation & Operator Overloading**
- Classes, Constructors and Destructors
- Dynamic Memory Allocation
- Static Members and Operator Overloading

**Unit III – Inheritance & Polymorphism**
- Multiple and Hybrid Inheritance
- Virtual Base Classes
- Composition and Runtime Polymorphism

**Unit IV – Advanced C++**
- Exception Handling
- Binary File Handling
- Templates and STL
- Functors and Stream Manipulators

## Technologies Used
- C++
- C++11
- Object-Oriented Programming
- Standard Template Library (STL)
